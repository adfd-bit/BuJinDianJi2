# STM32 障碍物监视器

`radar_visualizer.py` 使用 Tkinter 和 pyserial，读取 STM32 输出的换行 JSON 障碍物快照。目标识别在开发板完成，电脑显示图标和小车相对位置。

## 连接与启动

使用 3.3V TTL USB 转串口：适配器 RX 接 PA2 / USART2_TX、GND 与开发板共地，适配器 TX 不接。雷达 TX 接 PA10，雷达持续供电。

```powershell
py -m pip install -r tools/requirements.txt
py tools/radar_visualizer.py
```

也可双击根目录的 `run_visualizer.bat`。选择 USB-UART 的 COM 口，波特率保持 `230400`，数据格式为 8N1。

已有明确端口时，可使用 `py tools/radar_visualizer.py --port COM5` 启动后自动连接。

## 显示

- 场地图保留原场地和显示用车辆位姿，只将小车相对坐标投影到场地。
- 车体坐标障碍物图以小车中心为原点，X 向右、Y 向前；图标旁的数值单位为米。
- 雷达右/前各 106 mm 的安装偏移已由 STM32 补偿，界面没有安装角或拖动编辑。
- 每条报告替换整份障碍物列表，不累积历史图标。目标没有跨扫描 ID。
- 空列表、失效报告、断开串口、重连或扫描年龄达到 500 ms 均清除旧图标。

场地图不提供实时全场定位。原始雷达二进制流不能直接供这个版本的界面使用。

## 串口行为

协议见 [接口文档](../docs/RADAR_PORTING_GUIDE.md)。解析器支持分段和连续多行，检查版本、字段类型、有限坐标及八个目标上限；坏行丢弃并计数。超长行丢弃至下一个换行，避免截断尾部误解析。

界面根据开发板的 `age_ms` 和电脑单调时钟判断过期；重复收到同一扫描不能延长图标有效期。读线程只保留最新报告，由 Tk 主线程更新显示。

## 排查

`valid:false` 仍是正常状态报告：表示 STM32 在发送，但雷达没有新的有效完整扫描。若连状态报告也没有，检查 PA2、共地、COM 是否选错或被其他程序占用，并确认调试器已经继续运行。
